# S3 Website Deployment

## Purpose

The purpose of this exercise was to deploy my static website to Amazon S3.

## Deployment

I created an Amazon S3 bucket and selected an AWS Region for the project.

I uploaded the following website files:

* `index.html`
* `style.css`

## Static Website Hosting

I enabled static website hosting for the S3 bucket.

The index document was configured as:

```text
index.html
```

## Website Endpoint

The S3 website endpoint was generated by AWS after enabling static website hosting.

The endpoint is not included here because this project may later use a different deployment configuration.

## Access Configuration

At this stage, Amazon S3 Block Public Access remains enabled.

The website has therefore not yet been configured for unrestricted public access.

This is intentional because the next part of the project will investigate S3 access control and security.

## What I Learned

I learned how to:

* Create an S3 bucket
* Select an AWS Region
* Upload website files to S3
* Enable static website hosting
* Configure an index document
* Locate the S3 website endpoint

## Security Observation

S3 buckets are private by default through Block Public Access settings.

Making an S3 static website publicly accessible requires additional access configuration.

AWS recommends carefully considering the risks before allowing public access.
