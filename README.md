# AWS Static Website

## About

This is my Cloud Computing solo project for WeThinkCode_.

The goal of this project is to learn the basics of cloud computing by creating
a simple website and learning how to host it using AWS.

I am building this project as a beginner and will document my progress,
decisions, and what I learn along the way.

- Learn the basics of AWS
- Understand how cloud hosting works
