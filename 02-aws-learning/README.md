# AWS Learning

## Purpose

The purpose of this section is to document the AWS concepts I am learning before deploying my static website.

## 1. Amazon Web Services (AWS)

### What is AWS?

AWS is a cloud computing platform that provides different services for computing, storage, networking, databases and other technology needs.

### What I Learned

I learned that instead of running all infrastructure on my own physical computer or server, cloud services allow organisations and developers to use computing resources provided by a cloud provider.

### Relevance to My Project

My project is intended to help me understand how a simple website can be deployed using cloud infrastructure.

---

## 2. Amazon S3

### What is S3?

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data.

S3 stores data as objects inside containers called buckets.

### What I Learned

I learned that an S3 bucket can be used to store website files such as:

* HTML
* CSS
* JavaScript
* Images

I also learned that S3 can be used to host static websites.

### Relevance to My Project

My project is a static website, so S3 is relevant because the website files can be stored in an S3 bucket and served as a website.

---

## 3. AWS Regions

### What is an AWS Region?

An AWS Region is a geographic area where AWS has infrastructure for providing its cloud services.

### What I Learned

I learned that AWS provides multiple regions around the world.

The choice of region can affect factors such as latency, availability of services and pricing.

### Relevance to My Project

When deploying my website, I will need to choose an AWS Region for the resources I create.
